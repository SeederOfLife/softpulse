Tuner settings

Auto-detect recognises the set from the notes heard. Pick a pattern to have the other five notes calculated as soon as the root rings. Your saved sets appear here too.

Octave pairs

When a set has the same note twice (A and a, G and g…), the upper one is tuned this many cents above the lower one, to match the overtone. Example: A4 reads +0.46 ¢ → A5's target is +0.96 ¢. "Octave locked" lights up when the gap stays inside the lock zone.

Whole-chime check

Automatic: once all six tubes are measured, ringing the whole chime starts the check by itself. You can always press "Check the whole chime".

Rings to confirm a chime

Each strike is read as soon as the note is steady. The chime appears on the first ring, then its value is refined by averaging the following rings of the same note. After you grind, a clearly different ring starts a fresh average.

Precision shown

0.001 shows a third decimal in Hz and cents. On clean test tones the reading is accurate to about ±0.005 Hz; with a real mic and room noise the last digit will move more.

Number speed

Water: the digits glide smoothly to every new reading. Move Flow to the right to make them slower and calmer. The other speeds jump in steps and show the average of each step. The needle always moves in real time.

Re-ring averaged with the last rings within

If a new ring differs more than this, the tile shows the new ring straight away (for example after grinding).

Noise filter on the display

On: when the sound is only noise or not a clear note, the numbers hold still instead of jumping around.

Averaging time

Longer is more precise, shorter reacts faster.

Minimum identical notes

Share of recent readings that must agree before the display updates. Higher means less jitter.

Averaging range

Readings within this ± range are averaged together.

Analysis hold-off

How long a note must be heard without a break before the display goes live.

Trigger hysteresis

Higher stops notes flickering on and off at the edge of the noise trigger.
